📡 Day 9 Student REST API Endpoints

HTTP Method Endpoint Route Request Payload / Params Description
POST /api/students StudentRequestDto (JSON) Registers a new student record with uniqueness validation.
GET /api/students Query: department, yearOfStudy, status Retrieves all students or filtered by department / year / status.
GET /api/students/{id} Path Variable: id (Long) Fetches student details by primary database ID.
GET /api/students/roll/{rollNumber} Path Variable: rollNumber (String) Fetches student details by institutional roll number.
PUT /api/students/{id} StudentRequestDto (JSON) Updates existing student information with duplicate checks.
DELETE /api/students/{id} Path Variable: id (Long) Permanently deletes the student record.
