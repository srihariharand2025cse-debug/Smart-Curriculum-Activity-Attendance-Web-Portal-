📋 Activity Entity Database Schema

Column Name JPA Field Data Type Constraints / Notes
id Long id BIGINT PRIMARY KEY, AUTO_INCREMENT
activity_code String activityCode VARCHAR(50) NOT NULL, UNIQUE, INDEXED
title String title VARCHAR(150) NOT NULL
description String description VARCHAR(1000) Nullable (overview & syllabus)
activity_type String activityType VARCHAR(50) NOT NULL, INDEXED (LAB, LECTURE, WORKSHOP...)
department String department VARCHAR(100) NOT NULL, INDEXED
academic_year String academicYear VARCHAR(20) e.g. '2025-2026'
semester Integer semester INT Academic semester (1 to 8)
credits Integer credits INT Credits allocated (e.g. 1-4)
venue String venue VARCHAR(150) Lab / Hall location
faculty_id Faculty faculty BIGINT (FK) FOREIGN KEY -> faculty(id)
status String status VARCHAR(30) DEFAULT 'ACTIVE', INDEXED
created_at / updated_at LocalDateTime TIMESTAMP Auditing via @PrePersist / @PreUpdate
